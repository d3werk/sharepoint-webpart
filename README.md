# Copilot-FinOps

Die Anwendung liegt unter [Copilot-FinOps](Copilot-FinOps/README.md).

1. [Dashboard](Copilot-FinOps/04_Dashboard/copilot-cost-dashboard.html) lokal öffnen und mit Beispieldaten kennenlernen – ohne Installation oder Anmeldung.
2. Im [Schnellstart](Copilot-FinOps/01_Dokumentation/01_Schnellstart.md) den passenden Weg wählen: CSV ohne Tenant-Zugang, Graph mit App-Zertifikat oder Azure Query.
3. Einstellungen mit der [Browsermaske](Copilot-FinOps/02_Konfiguration/Konfiguration-CopilotFinOps.html) oder dem [lokalen Assistenten](Copilot-FinOps/03_Collector/Einrichten-CopilotFinOps.ps1) erstellen.

Der Assistent kann Tenant-ID und Azure-Abonnements nach einer Benutzeranmeldung ermitteln. App-Registrierung und Berechtigungen bleiben bei Graph/Azure Query erforderlich.
